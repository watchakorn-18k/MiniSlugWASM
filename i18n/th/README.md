# 🎮 MiniSlug (SDL2 + WASM Port)

[**English**](../en/README.md) | [**ไทย**](./README.md)

โปรเจกต์พอร์ตเกม MiniSlug จาก SDL 1.2 มาเป็น **SDL 2.0** พร้อมรองรับการทำงานบน **WebAssembly (WASM)** ผ่าน Emscripten ทำให้สามารถเล่นเกมนี้บนเว็บเบราว์เซอร์สมัยใหม่ได้ทันที

## ✨ ฟีเจอร์หลัก

- **SDL 2.0 Migration**: อัปเกรดระบบกราฟิก การควบคุม และเสียง ให้รองรับ SDL2
- **WebAssembly Support**: คอมไพล์และรันเกมบนเว็บเบราว์เซอร์ได้
- **Containerized Build System**: ใช้ **Podman/Docker** ในการ Build ไม่ต้องลงโปรแกรมหรือไลบรารีให้รกเครื่อง
- **Graphic Fixes**: แก้ไขปัญหาสีเพี้ยน (Blue Tint) บนหน้าจอสมัยใหม่ด้วยเทคนิค 16-bit Shadow Buffer

## 🚀 วิธีเล่น (ผ่านเว็บเบราว์เซอร์)

คุณสามารถรันไฟล์ที่คอมไพล์แล้วในเครื่องได้ดังนี้:

1.  เข้าไปที่โฟลเดอร์ build:
    ```bash
    cd wasm/build
    ```
2.  รัน HTTP Server (ต้องมี Python 3):
    ```bash
    python3 -m http.server 8080
    ```
3.  เปิดเบราว์เซอร์ไปที่: [http://localhost:8080/minislug.html](http://localhost:8080/minislug.html)

## 🛠️ วิธีการ Build (คอมไพล์โค้ด)

โปรเจกต์นี้ออกแบบมาให้ใช้ **Podman** (หรือ Docker) จัดการ Environment ทั้งหมด

### สิ่งที่ต้องมี
- **Podman** (แนะนำ) หรือ Docker

### 1. Native Build (สำหรับ Linux/macOS)
หากต้องการสร้างไฟล์ exe สำหรับเล่นในเครื่องคอมพิวเตอร์:

```bash
./build.sh
```
ไฟล์เกมจะอยู่ที่ `minislug0/minislug`

### 2. WebAssembly Build (สำหรับเว็บ)
หากต้องการสร้างไฟล์เว็บ (HTML/WASM):

```bash
./wasm/build.sh
```
ไฟล์ผลลัพธ์จะอยู่ที่ `wasm/build/`

## 🎮 การควบคุม

- **ปุ่มลูกศร (Arrow Keys)**: เคลื่อนที่ / บังคับทิศทาง
- **Space (เว้นวรรค)**: กระโดด
- **X**: ยิงปืน
- **Z**: ขว้างระเบิด

## 📂 โครงสร้างโปรเจกต์

- `minislug0/`: ซอร์สโค้ดภาษา C/C++
- `wasm/`: สคริปต์และ Dockerfile สำหรับทำ WASM
- `i18n/`: เอกสารประกอบภาษาต่างๆ

## 🧹 คุณภาพโค้ดและการตรวจสอบ (Linting)

เราควบคุมคุณภาพของโค้ดโดยใช้ **Clang-Tidy** ซึ่งทำงานใน Container เพื่อตรวจสอบและแก้ไขข้อผิดพลาดต่างๆ ในโค้ดเก่า เช่น การดำเนินการที่ไม่ปลอดภัย (Undefined Behavior)

### การรัน Lint Check
คำสั่งสำหรับตรวจสอบโค้ด:

```bash
./lint.sh
```

สคริปต์นี้จะทำการสร้าง Image สำหรับตรวจสอบและรันการตรวจสอบไฟล์ซอร์สโค้ดทั้งหมด พร้อมทั้งล้างไฟล์รายงานเก่าโดยอัตโนมัติ
